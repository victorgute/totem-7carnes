# Protótipo · Totem de autoatendimento da 7 Carnes Burger

Protótipo acadêmico (PUCRS Online, disciplina Empreendedorismo e Modelagem de Soluções, curso de Análise e Desenvolvimento de Sistemas).

O app de autoatendimento roda no totem da hamburgueria: o cliente monta o pedido sozinho, com toque e teclado na tela, e o pedido é impresso para pagamento no caixa.

**Abrir o protótipo:** use o link do GitHub Pages deste repositório.
